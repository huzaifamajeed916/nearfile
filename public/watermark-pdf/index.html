How to watermark a PDF

  1. Add your PDF. Drop it on the page, or tap Select PDF.
  2. Type the watermark. Use a word or short phrase, such as DRAFT or Do not copy.
  3. Style it. Pick a color, size and angle, and slide the opacity until the page still reads easily. The preview updates as you go.
  4. Add it and download. Mark every page, or choose pages like 1-3, 5.

Questions and answers

Is my PDF uploaded anywhere?

No. Nearfile adds the watermark inside this browser tab. Nothing is sent to a server, and closing the tab clears everything. Once the page has loaded, it even works offline.

Can someone remove the watermark?

It’s added on top of each page as ordinary text, so a person with PDF editing software could take it off. For stronger protection, run the watermarked file through Compress PDF with Flatten pages, which merges the mark into the page picture.

Can I use other alphabets or emoji?

Letters, numbers and common symbols in the Latin alphabet work, including accented letters like é and ñ. Other alphabets and emoji aren’t supported yet.

Can I add a logo or image?

Not yet. This tool adds text only.

Why does the text size change with the words I type?

The size is a share of the page, so longer text is set smaller to fit. Choose Large for the biggest mark that fits across the page.

Does it work on scanned PDFs?

Yes. The mark goes on top of whatever is on the page, whether that’s text or a scanned picture.

Can I use a password-protected PDF?

Not yet. If a PDF needs a password to open, or is locked against editing, open it in your PDF reader, save a copy without the protection, and use that copy.
