How to add page numbers to a PDF

  1. Add your PDF. Drop it on the page, or tap Select PDF.
  2. Choose where and how. Click a spot on the little page, then pick a style such as 3 or Page 3 of 10, and a size.
  3. Say where to start. Start on page 2 to leave a cover page bare. First number sets what the first numbered page shows.
  4. Add numbers and download. The preview shows the number on the first page it will appear on.

Questions and answers

Is my PDF uploaded anywhere?

No. Nearfile adds the numbers inside this browser tab. Nothing is sent to a server, and closing the tab clears everything. Once the page has loaded, it even works offline.

How do I skip the cover page?

Set Start on page to 2. The first page stays as it is, and numbering begins on page 2. First number decides what that page shows: 1 to count from the second page, or 2 to match the page’s position in the file.

What do “1 of 10” and “Page 1 of 10” count up to?

The last number that will be printed. If you start on page 2 of a 10-page PDF and the first number is 1, the last page reads 9, so you’ll see “9 of 9”.

Does it work on landscape and rotated pages?

Yes. Numbers are placed as each page looks on screen, so they stay upright and in the spot you chose, even on pages that were rotated.

Can I change the font or colour?

Not yet. Numbers are set in a plain dark gray sans-serif font that suits most documents.

Can I remove the numbers afterwards?

Not with Nearfile. The numbers are added to the pages themselves, so keep your original file if you might want it without them.

Can I use a password-protected PDF?

Not yet. If a PDF needs a password to open, or is locked against editing, open it in your PDF reader, save a copy without the protection, and use that copy.
